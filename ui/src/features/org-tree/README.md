# Org Tree

Business-layer authoring: org -> division -> tribe -> squad -> team CRUD,
drag-to-reparent, product/service assignment. Calls
`POST/PATCH/DELETE /api/org/*` (docs/API.md). This is the UI's write
surface for the business layer described in docs/architecture.md.

Implemented in Phase 16 (docs/phases/PHASE-16.md). See docs/UI.md
"Org Tree screen" for the component breakdown and interaction spec.
